飞书同步

在飞书多维表格里建一个「接收到 Webhook 时」的自动化，把地址填到这里。不同步也不影响本机使用。

飞书可能拦截浏览器跨域请求。发送后如果显示「同步待确认」，说明读不到飞书返回，请先到表格看一眼：已新增就点「我已确认写入」，没新增再重发。

飞书自动化怎么建
  1. 打开存放收藏的多维表格，右上角点「自动化」→ 新建。
  2. 触发条件选「接收到 Webhook 时」，复制生成的地址。
  3. 添加操作「新增记录」，目标选这张表，把 Webhook 的字段分别映射到：标题、视频链接、描述文案、口播文案、视频总结、作者、封面、处理状态、收藏时间、同步时间。
  4. 字段名保持中文；收藏时间和同步时间传的是毫秒时间戳，处理状态只能是「处理中 / 已完成 / 失败」。
  5. 保存并启用自动化，再回到这里点「发送测试」。

示例 JSON 里的字段就是实际发送的内容，可以直接对照映射。想避免重复记录，可以在自动化里先按「视频链接」查找记录：找到就更新，找不到再新增。

从飞书加载

飞书接口不允许网页直接读取。搭一个免费的 Cloudflare Worker 中转后，每次打开应用就会自动把表格里的链接合并到本机；不搭也不影响本机使用。

还没有配置中转。

Cloudflare Worker 怎么搭（一次性）
  1. 在飞书开放平台创建「企业自建应用」，权限里添加「查看多维表格」（bitable:app:readonly），创建版本并发布，等管理员通过。
  2. 打开这张多维表格，点右上角「…」→「添加文档应用」，把刚建的应用加进来，权限选可阅读。
  3. 记下应用的 App ID、App Secret；从多维表格地址里记下 /base/ 后面的 app_token，以及 ?table= 后面的 table_id。
  4. 打开 Cloudflare 控制台 → Workers & Pages → 创建 Worker，把中转代码整段粘贴进去并部署。
  5. 在 Worker 的变量里添加 FEISHU_APP_ID、FEISHU_APP_SECRET、FEISHU_APP_TOKEN、FEISHU_TABLE_ID、RELAY_TOKEN（自己设一个长口令）。App Secret 只放这里，不要填到网页里。
  6. 把 Worker 地址加上 /records 填到上面的「中转地址」，口令填到「中转口令」，点「测试连接」。

手机添加

iPhone：用快捷指令一键存入
  1. 打开「快捷指令」App，新建一个快捷指令。
  2. 添加操作「接收共享输入」，类型选 URL 和文本（可选）。
  3. 添加「URL 编码」操作，把共享输入编码，避免中文和空格弄坏链接。
  4. 再添加「打开 URL」，内容填本页地址，并在后面加 ?add=，把编码后的变量接在 add= 后面。
  5. 在抖音点分享 → 更多 → 选这个快捷指令，就能把链接存进来。
  6. 也可以在快捷指令里设置「轻点背面」运行。

快捷指令打开的是 Safari。iOS 的主屏幕 App 与 Safari 存储互不相通：想用快捷指令，就别把本页加到主屏幕；想用主屏幕 App，就在 App 里点「从剪贴板粘贴」。两边数据可用导出/导入迁移。

安卓：用系统分享直接存入
  1. 用 Chrome 打开本页，菜单里选「安装应用」或「添加到主屏幕」。
  2. 在抖音点分享 → 更多 → 选「视频收藏」。
  3. 第一次可能需要在系统分享面板里把「视频收藏」固定到常用。

保存与数据

Safari 长期不访问可能清理本机数据；建议同步到飞书，并每隔一段时间导出一次备份。
