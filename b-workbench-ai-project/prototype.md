## 交互流程

1. 右侧导航：点击窄图标栏图标（客户信息/待拨打/待跟进/联络历史/关联工单）切换右栏面板；AI知识库仅高亮
2. 软电话签入：点右上角电话图标 → 拨号盘弹窗 → 切「签入」→ 顶栏出现蓝色计时胶囊（原型默认已签入，显示 00:08:23 起走秒）
3. 发消息：输入框打字 → Enter 或点「发送」→ 右侧蓝色气泡追加到消息流并滚到底部；Shift+Enter 换行
4. Tab 切换：聊天区四个 Tab 点击切换激活态
5. 侧栏折叠：主导航右下箭头折叠整栏；dzim 底部按钮折叠沟通菜单为图标列
6. 会话计时：聊天区头部 ⏱ 从 08:08 起每秒递增
7. 会话卡片：hover 显示关闭图标，选中态浅蓝底
8. 会话报表：hover 主导航「数据运营」→ 弹出「会话报表」二级浮层（10 项）→ 点击「会话统计」整页切换为报表页（tab 按日/按小时、时区/日期/渠道筛选、数据表格含 ？ 口径图标、左对齐分页）；点击左侧已选中的「会话统计」返回工作台

## 状态设计

- 加载 / 空数据：会话列表空态可回退模板 `dz-empty--mini`；聊天区空态为模板 `.dz-empty`（本页默认展示进行中会话）
- 输入框空态：`:empty::before` 占位文案；客户栏字段均有 placeholder
- 必填校验、结束会话二次确认弹窗：待确认项，确认后可追加 form-dialog 结构
